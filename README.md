# Death-Of-Will
This repository is a first-person shooter with liminal spaces, whose objective is to have different entities (enemies) that modify their behavior depending on their perception system and other aspects such as Nav Mesh modifiers. In addition, we will seek to implement different PBR-type materials by applying the knowledge acquired in the subject's classes. This, together with a round system that allows for a good game loop and even allows the user to customize their own games.
